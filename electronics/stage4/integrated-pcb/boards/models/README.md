# Preserved KiCad package geometry

Standard STEP models here are copied unchanged from the installed KiCad 10
package library. Copyright belongs to their respective KiCad community authors;
the individual STEP files retain their authorship metadata. The upstream
[library source](https://gitlab.com/kicad/libraries/kicad-packages3D) and
[license](LICENSE.md) identify CC BY-SA 4.0 and KiCad's design-file exception.
This collection retains the upstream license notice. Board exports use these
models through portable relative paths. `../../package-models/` contains the
separately identified nominal SCCI_RH models for eight missing package patterns.
